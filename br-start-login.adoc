= 登录NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
从 NetApp Console 登录到 NetApp Backup and Recovery，以发现工作负载并管理保护操作。

NetApp Backup and Recovery使用身份和访问管理来控制每个用户可以做什么。

有关每个角色可以执行的操作的详细信息，请参阅link:reference-roles.html["NetApp Backup and Recovery用户角色"]。

要登录 NetApp Console，您可以使用您的 NetApp 支持站点凭据，也可以使用您的电子邮件地址和密码注册 NetApp Console 帐户 https://docs.netapp.com/us-en/console-setup-admin/task-logging-in.html["了解有关登录的更多信息"^]。

*必需的 NetApp Console 角色* 备份和恢复超级管理员或备份和恢复还原管理员。如果要保护存储在 Cloud Volumes ONTAP 集群上的数据，则还需要 Cloud Volumes ONTAP Admin 角色 https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["了解所有服务的NetApp Console访问角色"^]。

要添加控制台代理，您必须具有备份和恢复超级管理员角色。

.步骤
. 执行以下操作之一：
+
** 如果使用的是 NetApp Console，请打开 Web 浏览器并转到 https://console.netapp.com/["NetApp Console"^]。
** 如果使用的是 NetApp Console 本地部署，请打开 Web 浏览器并转到本地 Console 部署的 Web UI 的 IP 地址。
+
出现NetApp Console登录页面。



. 登录控制台。
. 从控制台左侧导航中，选择*保护*>*备份和恢复*。
+
** 如果这是您第一次登录 Backup and Recovery，并且您尚未将系统添加到 *Systems* 页面，则 Backup and Recovery 服务将显示"Welcome to the new NetApp Backup and Recovery"登录页面，其中包含添加系统的选项。有关将系统添加到 *Systems* 页面的详细信息，请参阅 https://docs.netapp.com/us-en/console-setup-admin/task-quick-start-standard-mode.html["NetApp Console标准模式入门"^]。
** 如果您是第一次登录备份和恢复，并且在控制台中有一个系统但没有发现任何资源，则会显示“欢迎使用新的NetApp备份和恢复”页面，其中包含“发现资源”选项。


. 如果您尚未完成此操作，请选择*发现和管理*。
+
** 有关 Microsoft SQL Server 工作负载，请参见 link:br-start-discover.html["发现 Microsoft SQL Server 工作负载"]。
** 有关 VMware 工作负载，请参见 link:br-use-vmware-discovery.html["发现 VMware 工作负载"]。
** 有关 KVM 工作负载，请参见 link:br-start-discover-kvm.html["发现 KVM 工作负载"]。
** 有关 Oracle 数据库工作负载，请参见 link:br-start-discover-oracle.html["发现 Oracle Database 工作负载"]。
** 有关 Hyper-V 工作负载，请参见 link:br-start-discover-hyperv.html["发现 Hyper-V 工作负载"]。
** 有关 Kubernetes 工作负载，请参见 link:br-start-discover-kubernetes.html["发现 Kubernetes 工作负载"]。
