= VMware 工作负载在 NetApp Backup and Recovery 中的已知限制
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
在使用适用于 VMware 工作负载的 NetApp Backup and Recovery 之前，请查看这些限制。

NetApp Backup and Recovery 不支持对 VMware 工作负载执行以下操作：

* 在适用于 NetApp Console 本地部署的 Backup and Recovery 预览版本中，仅 ONTAP S3 和 StorageGRID 目标支持备份到对象存储。此预览版本不支持备份归档。
* vVol 支持
* 电子邮件集成
* 基于角色的访问控制 (RBAC) 支持
