= 监控NetApp Backup and Recovery中的作业
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
监视快照、复制、备份和还原作业。配置电子邮件通知并使用 Console Timeline 来调查活动。

NetApp Backup and Recovery 将作业信息保留 90 天，然后将其删除并从作业监视器中移除。

*必需的 NetApp Console 角色* Backup and Recovery 超级管理员、Backup and Recovery 备份管理员、Backup and Recovery 恢复管理员、Backup and Recovery 克隆管理员或 Backup and Recovery 查看器角色。如果要保护存储在 Cloud Volumes ONTAP 集群上的数据，则还需要 Cloud Volumes ONTAP 管理员角色。了解link:reference-roles.html["备份和恢复角色和权限"]。 https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["了解所有服务的NetApp Console访问角色"^]。



[[view-job-status-on-the-job-monitor]]
== 在作业监视器上查看作业状态

您可以在“作业监控”选项卡中查看所有快照、复制、备份到对象存储和恢复操作的列表及其当前状态。这包括来自您的Cloud Volumes ONTAP、本地ONTAP、应用程序和虚拟机的操作。每个操作或作业都有唯一的 ID 和状态。

状态可以是：

* 成功
* 进行中
* 已排队
* 警告
* 失败


您从NetApp Backup and RecoveryUI 和 API 启动的快照、复制、对象存储备份和还原操作均可在“作业监控”选项卡中找到。


NOTE: 如果您已将ONTAP系统升级到 9.13.x，但在作业监视器中没有看到正在进行的计划备份操作，请重新启动NetApp Backup and Recovery。link:reference-restart-backup.html["了解如何重新启动NetApp Backup and Recovery"]。

.步骤
. 从NetApp Backup and Recovery菜单中，选择 *监控*。
. 要显示其他列（系统、存储虚拟机、用户名、工作负载、策略名称、快照标签），请选择加号。




[[search-and-filter-the-list-of-jobs]]
=== 搜索并过滤职位列表

可以使用多个筛选器（例如策略、快照标签、操作类型（保护、还原、保留或其他）和保护类型（本地快照、复制或备份到云））来筛选作业监视页面上的操作。

默认情况下，“作业监控”页面显示过去 24 小时的保护和恢复作业。您可以使用时间范围过滤器更改时间范围。

.步骤
. 从NetApp Backup and Recovery菜单中，选择 *监控*。
. 要对结果进行不同的排序，请选择每个列标题以按状态、开始时间、资源名称等进行排序。
. 如果您正在寻找特定的工作，请选择“高级搜索和过滤”区域以打开“搜索”面板。
+
使用此面板可输入任何资源的自由文本搜索；例如，"volume 1"或"application 3"。您还可以根据下拉菜单中的项目筛选作业列表。

+
大多数过滤器都是不言自明的。通过“工作量”过滤器，您可以查看以下类别的作业：

+
** ONTAP卷（Cloud Volumes ONTAP和本地ONTAP卷）
** Microsoft SQL Server
** 虚拟机
** Kubernetes


+
[TIP]
====
** 只有在首先选择了系统的情况下，才能搜索特定存储 VM 中的数据。
** 只有当您选择了“保护”的“类型”时，您才可以使用“保护类型”过滤器进行搜索。


====
. 要立即更新页面，请选择image:button_refresh.png["刷新"]按钮。否则，此页面每 15 分钟刷新一次，以便您始终看到最新的工作状态结果。




[[view-job-details]]
=== 查看职位详情

您可以查看与特定已完成作业对应的详细信息。您可以以 JSON 格式导出特定作业的详细信息。

您可以查看详细信息，例如作业类型（计划或按需）、SnapMirror 备份类型（初始或定期）、开始和结束时间、持续时间、从系统到对象存储的传输数据量、平均传输速率、策略名称、启用的保留锁定、执行的勒索软件扫描、保护源详细信息和保护目标详细信息。

还原作业显示备份目标提供程序（Amazon Web Services、Microsoft Azure、Google Cloud、本地）、S3 存储桶名称、存储 VM 名称、源卷名称、目标卷、快照标签、已恢复对象计数、文件名、文件大小、上次修改日期和完整文件路径等详细信息。

.步骤
. 从NetApp Backup and Recovery菜单中，选择 *监控*。
. 选择作业的名称。
. 选择"操作"菜单image:icon-action.png["操作图标"]，然后选择"查看详细信息"。
. 展开每个部分以查看详细信息。




[[download-job-monitoring-results-as-a-report]]
=== 下载作业监控结果报告

在筛选或排序结果后，您可以将主作业监控页面的内容作为报告下载。NetApp Backup and Recovery 会生成并下载一个 CSV 文件，您可以根据需要查看并发送给其他组。CSV 文件最多包含 10,000 行数据。

从作业监控详细信息中，您可以下载包含单个作业详细信息的 JSON 文件。

.步骤
. 从NetApp Backup and Recovery菜单中，选择 *监控*。
. 要下载所有作业的 CSV 文件，请选择“下载”按钮并在下载目录中找到该文件。
. 要下载单个作业的 JSON 文件，请选择“操作”菜单image:icon-action.png["操作图标"]对于该作业，选择*下载 JSON 文件*，然后在下载目录中找到该文件。




[[review-retention-backup-lifecycle-jobs]]
== 审查保留（备份生命周期）作业

监控保留（_backup lifecycle_）作业，以跟踪备份副本何时过期并支持审核。

备份生命周期作业跟踪所有已删除或正在排队等待删除的快照。从ONTAP 9.13 开始，您可以在“作业监控”页面上查看所有名为“保留”的作业类型。

“保留”作业类型捕获在受NetApp Backup and Recovery保护的卷上启动的所有快照删除作业。

.步骤
. 从NetApp Backup and Recovery菜单中，选择 *监控*。
. 选择“高级搜索和过滤”区域以打开搜索面板。
. 选择“保留”作为工作类型。

== 在NetApp Console通知中心查看备份和恢复警报

NetApp Console 通知中心跟踪您已启动的备份和还原作业的进度，以便您可以验证操作是否成功。

您可以在通知中心查看警报，并配置控制台以发送重要系统活动的电子邮件警报，即使您未登录。 https://docs.netapp.com/us-en/console-setup-admin/task-monitor-cm-operations.html["了解有关通知中心以及如何发送备份和恢复作业警报电子邮件的更多信息"^] 。

|===
| 操作类型 | 事件 | 已生成警报 | 电子邮件已发送 


| 激活 | 系统备份和恢复激活失败 | 是 | 是

| 激活 | 系统备份和恢复编辑失败 | 是 | 是 


| 激活 | 卷现在与快照策略关联 | 是 | 是 


| 激活 | 卷备份或状态已修改 | 是 | 是

| 酒吧/订阅活动 | 卷恢复成功 | 是 | 否 


| 酒吧/订阅活动 | 卷恢复失败 | 是 | 否 


| 勒索软件 | 在备份副本上发现潜在的勒索软件攻击 | 是 | 是

| 本地快照 | NetApp Backup and Recovery临时快照创建作业失败 | 是 | 是

[[cancel-an-ongoing-job]]
== 取消正在进行的作业

某些备份和恢复工作负载支持取消正在进行的作业（如果该作业完成时间过长且尚未失败）。


NOTE: 要取消 ONTAP 卷还原作业，请参阅 <<取消 ONTAP Volumes 还原作业>>。

.步骤
. 从NetApp Backup and Recovery菜单中，选择 *监控*。
. （可选）展开*高级搜索和过滤*区域，并选择特定条件以缩小作业搜索结果的范围。
. 选择*搜索*以显示匹配的还原作业。
. 从列表中选择一个作业，选择操作菜单image:icon-action.png["操作图标"]，然后选择*取消*操作（操作标签因作业类型而异）。
. 在确认对话框中，确认取消。




[[cancel-an-ontap-volumes-restore-job]]
== 取消 ONTAP Volumes 还原作业

如果 ONTAP Volumes 还原作业完成时间过长且未失败，请将其取消。

取消卷还原时，会回滚整个还原操作，以便不还原卷的任何部分。

在文件和文件夹还原期间，备份和恢复将分八批还原文件。如果在批处理正在执行时取消文件和文件夹还原，则还原将在下一批处理开始之前停止。已还原的任何文件和文件夹都将保留到位。

.关于此任务
请注意您可以和不能取消的作业类型：

[cols="1,1"]
|===
| 您可以取消 | 您不能取消 


| 从本地或云快照还原卷（FlexVol 和 FlexGroup） | 已排队的还原作业 


| 从云端还原文件和文件夹 | 存档还原 


| 将文件和文件夹从本地快照还原到其他卷 | 将文件和文件夹从本地快照还原到同一个卷 
|===
.步骤
. 从NetApp Backup and Recovery菜单中，选择 *监控*。
. （可选）展开*高级搜索和过滤*区域，并选择特定条件以缩小作业搜索结果的范围。
. 选择*搜索*以显示匹配的还原作业。
. 从列表中选择一个作业，选择操作菜单image:icon-action.png["操作图标"]，然后选择*取消还原*操作。
. 在确认对话框中，选择*取消还原*。
