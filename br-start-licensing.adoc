= 设置NetApp Backup and Recovery 的许可
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
通过使用市场订阅或来自 NetApp 的自带许可证（BYOL），在 NetApp Console 或 NetApp Console 本地部署中为 NetApp Backup and Recovery 设置许可。要将工作负载保护到对象存储并从对象存储还原数据，需要有效的许可证。本地快照和复制到 ONTAP 辅助存储不需要许可证。

有关许可证工作原理的一些注意事项：

* 对于所有工作负载，仅向您收取对象存储保护费用（例如，使用 3-2-1 备份体系结构或磁盘到对象存储）。本地快照和到 ONTAP 辅助存储的复制是免费的。
* Oracle Database 工作负载不需要许可证，因为它处于预览发布状态。
* 使用 ONTAP Volumes 工作负载时，可以在没有许可证的情况下发现和还原卷。但是，如果您需要将卷保护（备份）到对象存储，则需要购买许可证。
* 如果使用带有 NetApp Console 本地部署的 Backup and Recovery，则只能购买自带许可证 (BYOL) 许可证。
* NetApp Backup and Recovery自带许可证 (BYOL) 是一种浮动许可证，您可以在与NetApp Console组织或帐户关联的所有系统中使用它。因此，如果您现有的 BYOL 许可证具有足够的备份容量，则无需购买另一个 BYOL 许可证。
* 如果您在 NetApp Console 中使用 BYOL 许可证，建议您也订阅 PAYGO 订阅。如果您备份的数据超过 BYOL 许可证允许的数据量，或者许可证期限已过期，则备份将通过按需付费 (PAYGO) 订阅继续进行，不会中断服务。
* 将本地 ONTAP 数据备份到 StorageGRID 时，您需要 BYOL 许可证，但无需支付云提供商存储空间费用。


link:concept-backup-to-cloud.html["了解有关使用NetApp Backup and Recovery 的成本的更多信息。"]



[[licensing-options-for-netapp-backup-and-recovery]]
== NetApp Backup and Recovery 的许可选项

您有三种 NetApp Backup and Recovery 许可选项：

* 从 NetApp 购买直接许可证，也称为自带许可证 (BYOL)。此选项适用于 NetApp Console 和 Console 本地部署。
* 从超大规模云提供商市场购买年度合同。此选项仅适用于 NetApp Console。
* 从超大规模云服务商市场订阅按需付费 (PAYGO) 许可证。此选项仅适用于 NetApp Console。




[[30-day-free-trial]]
=== 30天免费试用

除 ONTAP Volumes 工作负载外，所有未经许可的工作负载均可免费试用 30 天 NetApp Backup and Recovery。您可以在开始使用工作负载时，在发现其资源之前开始试用。开始试用后，其状态和已用容量将显示在 NetApp Backup and Recovery 主页上的 *免费试用* 下。只有受保护到对象存储的容量才计入试用。受本地快照或复制到 ONTAP 辅助存储保护的容量不计算在内。



==== 结束免费试用

您可以随时从登录 NetApp Backup and Recovery 时显示的主页结束工作负载的免费试用。如果要在免费试用期结束后继续将工作负载保护到对象存储，则必须在 NetApp Console 界面的 *Licenses and subscriptions* 部分中设置付费订阅。不使用对象存储的保护（例如本地快照和到 ONTAP 辅助存储的复制）将继续工作，并且可以在没有付费订阅的情况下进行管理。如果不想继续将工作负载保护到对象存储，则无需订阅付费套餐即可结束免费试用。您可以在试用期结束前 link:prev-ontap-backup-manage.html["从系统中取消注册NetApp Backup and Recovery"]，并且不会向您收取费用。

.步骤
. 从 NetApp Backup and Recovery 主页中，在 *免费试用* 下选择要结束的免费试用。
. 选择*结束免费试用*。
. 在框中输入*结束试用*。
. 选择 *End trial* 确认。




[[use-a-byol-license]]
=== 使用 BYOL 许可证

来自 NetApp 的自带许可证提供 1 年、2 年或 3 年的期限。您只需为保护到对象存储的数据付费，该费用根据正在备份到对象存储的源工作负载的逻辑已用容量（在应用任何效率_之前_）计算。对于 ONTAP 卷，此容量也称为前端 TB （FETB）。仅通过本地快照或复制到 ONTAP 辅助存储进行保护的数据不会计入您的许可容量。

BYOL NetApp Backup and Recovery 许可证是一个浮动许可证，其中总容量在与您的 NetApp Console 组织或帐户关联的所有系统之间共享。对于 ONTAP 卷，您可以通过对计划备份到对象存储的卷运行 CLI 命令 `volume show -fields logical-used-by-afs`来粗略估计所需的容量。

如果您没有 NetApp Backup and Recovery BYOL 许可证，请联系您的 NetApp 销售代表购买。

您可以使用 NetApp Console 或 NetApp Console 本地部署来管理 BYOL 许可证。您可以从控制台添加新许可证、更新现有许可证和查看许可证状态。

https://docs.netapp.com/us-en/console-licenses-subscriptions/task-manage-data-services-licenses.html["了解如何添加许可证"^]。



[[use-an-annual-marketplace-subscription-applies-to-netapp-console-only]]
=== 使用年度市场订阅（仅适用于 NetApp Console）

您可以通过购买年度合同每年支付 NetApp Backup and Recovery 费用，该合同有多种期限选项可供选择。

根据来自市场的年度合同，用于保护对象存储的所有 NetApp Backup and Recovery 消耗都将根据该合同收取费用。

关于年度市场合同选项，请注意以下几点：

* 年度合约可在每个市场以私有优惠的形式提供。
* 年度合同使您能够同时备份 Cloud Volumes ONTAP 数据和本地 ONTAP 数据。
* 您可以从 marketplace 页面注册年度合同。从 Marketplace 页面设置您的订阅，然后将该订阅与您的 https://docs.netapp.com/us-en/console-setup-admin/task-adding-aws-accounts.html["AWS"^]、 https://docs.netapp.com/us-en/console-setup-admin/task-adding-azure-accounts.html#subscribe["Azure"^]或 GCP 凭据关联。请注意，您还需要使用此年度合同订阅为 Cloud Volumes ONTAP 系统付费，因为您只能在控制台中将一个有效订阅分配给您的 AWS 凭据。
* 如果您购买“CVO Professional”套餐，它将包含已获许可的 Cloud Volumes ONTAP 系统的无限备份，并且这些备份不计入许可容量。此套餐不支持备份本地 ONTAP 数据或通过 Freemium 或 Essentials 软件包获得许可的 Cloud Volumes ONTAP 系统；仅支持通过 Professional 软件包获得许可的 Cloud Volumes ONTAP 系统。
+
请参阅 https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/concept-licensing.html["Cloud Volumes ONTAP许可主题"^]以了解有关此许可选项的更多信息。



当您使用 AWS 或 Azure 时，请使用这些链接订阅 NetApp Backup and Recovery 的年度市场订阅：

=== 使用 NetApp Backup and Recovery PAYGO 订阅（仅适用于 NetApp Console）

对于按需付费，您可以在单个订阅中按小时向云提供商支付对象存储成本和 NetApp 备份许可成本。即使您拥有免费试用版或自带许可证 (BYOL)，也应在 Marketplace 中订阅 *NetApp Intelligent Services*：

* 订阅可确保在免费试用期结束后不会中断服务。试用期结束后，系统将根据您备份到对象存储的数据量按小时向您收费。
* 如果您备份的数据超出了 BYOL 许可证允许的范围，则数据备份和恢复操作将通过即用即付订阅继续进行。例如，如果您拥有 10 TiB BYOL 许可证，则超过 10 TiB 的所有容量都将通过 PAYGO 订阅收费。


在免费试用期间或未超出 BYOL 许可证的情况下，您无需支付即用即付订阅费用。

https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/concept-licensing.html#capacity-based-licensing["了解有关这些基于容量的许可证包的更多信息"]。

+

[[exceeding-license-capacity]]
== 超出许可证容量

超出您授权的对象存储保护容量会触发 PAYGO 费率。如果没有 PAYGO 订阅，您将无法创建对象存储的新备份，尽管您仍然可以在没有服务保证的情况下还原现有备份。本地快照和到 ONTAP 辅助存储的复制不受影响。在许可证过期之前续订许可证，因为过期的许可证会阻止对象存储的新备份并中断服务。



[[what-happens-when-your-license-expires]]
== 许可证过期后会发生什么

当您的备份和恢复许可证到期时：

* 现有备份策略的备份和还原将继续正常运行。
* 您无法创建保护到对象存储的新备份策略，也无法将对象存储保护扩展到其他工作负载和数据存储。
* 您仍然可以创建和管理不使用对象存储的策略，例如本地快照和复制到 ONTAP 辅助存储的策略。
* 您无法使用新的 Backup and Recovery 功能和增强功能。
* NetApp 技术支持的备份和恢复功能不再可用。


续订您的许可证，以便：

* 创建和修改保护到对象存储的备份策略，包括数据库、虚拟机和 Kubernetes 工作负载的应用程序一致性备份策略。
* 使用新的 Backup and Recovery 功能和增强功能。
* 继续获得 NetApp 技术支持。
