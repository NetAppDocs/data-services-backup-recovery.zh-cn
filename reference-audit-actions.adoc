= 审核 NetApp Backup and Recovery 操作
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
使用此参考资料查看 NetApp Console 在"审核"页面上记录的 NetApp Backup and Recovery 操作。有关查看和筛选审计事件的详细信息，请参见 NetApp Console 文档中的 https://docs.netapp.com/us-en/console-setup-admin/task-monitor-cm-operations.html#audit-user-activity-from-the-audit-page["从"审核"页面审核用户活动"^]。

对于每个已审核的操作，NetApp Console 都会记录服务名称、代理、资源、用户和操作状态。

[cols="1,3"]
|===
| 类别 | 操作 


| 还原和恢复  a| 
* 从 Snapshot 还原文件
* 从备份还原卷或文件
* 将卷还原为快照
* 启动文件资源管理器




| 备份和快照操作  a| 
* 创建临时云备份
* 创建临时快照
* 删除 Azure NetApp Files 快照策略
* 在卷中启用备份
* 刷新卷备份元数据（计划）




| 保护和复制  a| 
* 初始化系统保护
* 初始化源保护
* 初始化目标保护
* 用于保护的对等集群
* 启动卷复制




| 全景保护  a| 
* 激活系统中的全景保护
* 启用卷的全景保护
* 修改卷的全景保护
* 修改系统中的全景保护




| 备份迁移  a| 
* 在 ONTAP 系统之间迁移备份
* 验证备份迁移




| Cyber Vault 管理  a| 
* 创建 Cyber Vault 系统
* 删除 Cyber Vault 系统
* 禁用 Cyber Vault 访问权限
* 启用 Cyber Vault 访问权限




| 对象存储管理  a| 
* 创建对象存储桶
* 修改对象存储桶
* 修改系统的对象存储




| 云凭据管理  a| 
* 删除云凭据
* 注册云凭据
* 更新云凭据




| 发现和配置  a| 
* 发现卷和关系
* 更新应用程序配置


|===
