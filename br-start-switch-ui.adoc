NetApp Backup and Recovery 支持多种工作负载类型，某些工作负载使用不同的 UI。使用工作负载切换器在它们之间切换。



[[switch-to-a-different-workload]]
== 切换到不同的工作负载

您可以在NetApp Backup and RecoveryUI 中切换到不同的工作负载。

.步骤
. 从控制台左侧导航中，选择*保护*>*备份和恢复*。
. 从页面右上角，选择*切换工作负载*下拉列表。
. 选择您想要切换到的工作负载。
+
页面刷新并显示所选的工作负载。
