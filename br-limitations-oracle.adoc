= 适用于 Oracle 数据库工作负载的 NetApp Backup and Recovery 的已知限制
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
查看 NetApp Backup and Recovery 中 Oracle 数据库工作负载的当前限制和不支持的操作。

NetApp Backup and Recovery 预览版中的 Oracle 数据库工作负载不支持以下操作：

* 在适用于 NetApp Console 本地部署的 Backup and Recovery 预览版本中，仅 ONTAP S3 和 StorageGRID 目标支持备份到对象存储。此预览版本不支持备份归档。
* 脱机备份
