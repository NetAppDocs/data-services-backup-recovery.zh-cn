= 通过 NetApp Backup and Recovery 保护 VMware 工作负载
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
使用 NetApp Backup and Recovery 来保护 VMware 虚拟机和数据存储。您可以创建快速、节省空间、崩溃一致性和虚拟机一致性的备份，将其存储在受支持的备份目标上，并将 VMware 工作负载恢复到本地 VMware 主机。


NOTE: 此版本的NetApp Backup and Recovery仅支持 VMware vCenter，并且无法发现vVols或vVols上的 VM。

使用 NetApp Backup and Recovery 实施 3-2-1 策略，在 2 个不同的存储系统上保留 3 个源数据副本，并在云中保留 1 个副本。3-2-1 方法的优势包括：

* 多个数据副本可防止内部和外部网络安全威胁。
* 如果一种媒体发生故障，使用不同类型的媒体可以帮助您恢复。
* 您可以从现场副本快速还原，并在现场副本受损时使用非现场副本。

* link:br-use-vmware-protection-groups.html["为 VMware 工作负载创建和管理保护组"]
* link:br-use-vmware-backup.html["备份 VMware 工作负载"]
* link:br-use-vmware-restore.html["恢复 VMware 工作负载"]
