= NetApp Backup and Recovery针对 KVM 工作负载的已知限制
:hardbreaks:

:nofooter: 
:icons: font

[role="lead"]
查看 NetApp Backup and Recovery 中 KVM 工作负载的当前限制。

以下不受支持的操作和配置适用于 NetApp Backup and Recovery 中的 KVM 工作负载：



[[unsupported-actions]]
== 不支持的操作

不支持以下操作：

* 在适用于 NetApp Console 本地部署的 Backup and Recovery 预览版本中，仅 ONTAP S3 和 StorageGRID 目标支持备份到对象存储。此预览版本不支持备份归档。
* 克隆、挂载或卸载虚拟机
* 保护存储在 SAN 上的虚拟机
* 保护应用程序
* 创建用户定义的备份（仅支持从NetApp Console启动的备份）




[[unsupported-configurations]]
== 不支持的配置

不支持以下配置：

* 基于角色的访问控制 (RBAC)
* 直接连接到 KVM 主机的磁盘
* 跨多个 NFS 挂载点或共享的磁盘
* RAW磁盘格式
* NetFS 以外的存储池类型（仅支持 NetFS）




[[troubleshooting-notes]]
== 故障排除说明

当您将 KVM 工作负载与 NetApp Backup and Recovery 一起使用时，请注意以下几点。

* 如果 QEMU Guest Agent 未在受保护的虚拟机中运行，则备份可能会失败。要避免此问题，请确保在启动备份之前， `qemu-guest-agent`守护程序正在虚拟机上运行。
