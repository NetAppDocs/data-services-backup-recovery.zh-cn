= 使用 NetApp Backup and Recovery 的 KVM 保护工作流
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
使用 NetApp Backup and Recovery 保护您的托管 KVM 虚拟机和存储池。该服务提供快速、节省空间、崩溃一致性和虚拟机一致性的备份和还原操作。

您的 KVM 主机和虚拟机必须由 Apache CloudStack 等平台进行管理，然后才能通过 NetApp Backup and Recovery 对其进行保护。

使用NetApp Backup and Recovery实施 3-2-1 保护策略，其中您在 2 个不同的存储系统上拥有 3 个源数据副本，并在云中拥有 1 个副本。3-2-1 方法的优点包括：

* 多个数据副本可防止内部和外部网络安全威胁。
* 使用不同的介质类型有助于在某种类型发生故障时进行恢复。
* 您可以从现场副本快速恢复，如果现场副本受到损害，则可以使用异地副本。


您可以使用 NetApp Backup and Recovery 为 KVM 工作负载执行以下任务：

* link:br-start-discover-kvm.html["发现 KVM 工作负载"]
* link:br-use-kvm-protection-groups.html["为 KVM 工作负载创建和管理保护组"]
* link:br-use-kvm-backup.html["备份 KVM 工作负载"]
* link:br-use-kvm-restore.html["恢复 KVM 工作负载"]
