= 使用NetApp Backup and RecoveryVMware 工作负载
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
将 VMware VM 和数据存储区从本地ONTAP系统备份到 Amazon Web Services、 Azure NetApp Files或StorageGRID，以确保您的数据受到保护。备份会自动生成并存储在您的公共或私有云帐户的对象存储中。

* 若要按计划备份工作负载，请创建管理备份和还原操作的策略。有关说明，请参阅 link:br-use-policies-create.html["创建保护策略"]。
* 创建保护组以管理一组资源的备份和还原操作。有关更多信息，请参见 link:br-use-vmware-protection-groups.html["创建和管理保护组"]。
* 立即备份工作负载（立即创建按需备份）。




[[back-up-workloads-now-with-an-on-demand-backup]]
== 立即使用按需备份来备份工作负载

立即创建按需备份。如果您要对系统进行更改并希望确保在开始之前有备份，则可能需要运行按需备份。

*必需的 NetApp Console 角色* 存储查看器、备份和恢复超级管理员、备份和恢复备份管理员、备份和恢复恢复管理员、备份和恢复克隆管理员或备份和恢复查看器角色。如果要保护存储在 Cloud Volumes ONTAP 集群上的数据，则还需要 Cloud Volumes ONTAP 管理员角色 https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["了解所有服务的NetApp Console访问角色"^]。

.步骤
. 从备份和恢复菜单中，选择*库存*。
. 选择 VMware 工作负载。
. 选择“操作”图标image:../media/icon-action.png["操作选项"]> *查看详情*。
. 选择 *Protection Groups*、*Datastores*、*Virtual machines* 或 *Tags* 菜单标题。
. 选择要备份的保护组、数据存储库、虚拟机或标记的资源。
. 选择“操作”图标image:../media/icon-action.png["操作选项"]> *立即备份*。
+

NOTE: 应用于备份的策略与分配给保护组、数据存储、虚拟机或标记资源的策略相同。

. 选择计划层级。
. 选择*立即备份*。




[[delete-backups]]
== 删除备份

您可以删除不再需要的本地备份，以释放存储空间或满足数据保留要求。

.步骤
. 登录到 NetApp Backup and Recovery，然后从主屏幕中选择 VMware 工作负载磁贴。
+
此时将显示 VMware 清单页面。

. 选择*虚拟机*标题。
. 在虚拟机列表中，选择虚拟机并选择操作图标 image:../media/icon-action.png["操作选项"] > *查看保护详细信息*。
. 选择时间范围以显示相关快照。
. 删除一个或多个快照：
+
[role="tabbed-block"]
====
.删除单个Snapshot
--
.. 从列表中选择要删除的快照，然后选择操作图标 image:../media/icon-action.png["操作选项"] > *删除本地快照*。


--
.删除多个快照
--
.. 选中要删除的每个快照左侧的复选框。
.. 选择*删除所选内容*。


--
====
